STATIC SECURITY

On-Site Security Personnel

Static security provides dedicated security personnel positioned at a client's premises to support the protection of people, property, facilities and daily operations.

Security duties can be structured according to the nature of the site, operating hours, access requirements and the client's security procedures.

Key Responsibilities

  • Access and entry monitoring
  • Visitor management
  • Premises observation
  • Patrolling assigned areas
  • Incident reporting
  • Supporting emergency procedures
  • Maintaining security records
  • Following site-specific procedures
