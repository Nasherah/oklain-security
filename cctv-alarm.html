Technology-Supported Security

CCTV and alarm systems can provide important information about activity around a property. Oklain Security can support the physical security procedures associated with these systems.

Where applicable, security personnel can monitor designated areas, respond to reported security events and document observations according to agreed procedures.

Key Activities

  • Responding to reported alarm events
  • Checking relevant site areas
  • Reporting security observations
  • Supporting incident procedures
  • Maintaining incident records
  • Communicating with responsible personnel
  • Following client response procedures
