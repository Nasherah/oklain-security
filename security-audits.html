Reviewing Your Security Environment

A security audit provides an opportunity to review existing security arrangements, procedures and operational practices at a site.

Oklain Security can conduct structured reviews based on the client's requirements and the nature of the facility being assessed.

Audit Areas

  • Security post arrangements

  • Visitor management procedures

  • Security documentation
  • General site security practices
